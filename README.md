# 🏠 Surat Property Data Cleaning & Analysis

## 📌 Project Overview

This project focuses on cleaning, preprocessing, analyzing, and visualizing property data from Surat using Python.

The main objective of this project is to transform raw property data into clean and meaningful information and generate useful insights related to property prices, property sizes, and price per square foot.

---

## 🎯 Objectives

- Clean and preprocess raw property data
- Handle missing and invalid values
- Remove duplicate records
- Analyze property prices
- Analyze property sizes
- Calculate price per square foot
- Identify useful patterns and trends
- Create visualizations for better understanding
- Generate business-oriented property insights

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
